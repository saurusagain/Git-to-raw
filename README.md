## 📖 About Project

**Git to Raw** is a modern, lightweight web utility designed to solve a common friction point in web development and open source sharing: converting standard GitHub file URLs (with the `/blob/` path) into direct raw URLs (`raw.githubusercontent.com`) that can be safely embedded in web apps, markdown documents, scripts, and media players.

### ✨ Key Features
- **⚡ Instant Conversion**: Automatically detects and transforms GitHub blob URLs into raw usercontent links.
- **📋 One-Click Copy**: Seamless copy with automatic clipboard management and smooth SVG notification feedback.
- **🌙 Sleek Dark Theme**: Modern dark palette with electric blue glow, crafted with high-contrast accessibility in mind.
- **📱 PWA Ready**: Installable as a Progressive Web App on mobile and desktop platforms.
- **🔒 Private & Secure**: 100% client-side processing. Your URLs and data never leave your browser.

---

## 🚀 Quick Start

1. Visit **Git to Raw** in your browser.
2. Paste any GitHub file link (e.g., `https://github.com/username/repo/blob/main/index.html`).
3. Click the convert button or press **Enter**.
4. The converted raw link is generated and automatically copied to your clipboard!
